# 범위와 지원 수준

> 기준일: 2026-08-31  
> 프로젝트 코드명: `hwpx-agent`  
> 문서 세트 버전: `2.0-design`  
> 규범 키워드: **MUST/SHALL=필수**, **SHOULD=권장**, **MAY=선택**


## 범위 축

모든 기능은 다음 네 축으로 분류한다.

1. `artifact_semantics`: HWPX/HWP 파일에 저장되는 문서 의미.
2. `editor_workflow`: 선택·찾기·붙이기·실행처럼 편집기 동작에 속하는 기능.
3. `workstation_ui`: 화면 확대, 작업 창, 도구 상자처럼 문서 결과와 무관한 환경 설정.
4. `external_service`: 번역, 사전, 한컴독스, 메일, OCR처럼 외부 서비스 또는 별도 제품 의존 기능.

## 지원 수준

| 값 | 의미 | 사용자에게 표시할 문구 |
|---|---|---|
| `DIRECT_FULL` | Direct HWPX 경로만으로 생성·편집·검증 | 직접 지원 |
| `AUTOMATION_FULL` | 실제 한/글 자동화 경로에서 완전 지원 | 한/글 워커 필요 |
| `HYBRID` | 직접 편집 후 한/글 normalize/oracle 필요 | 하이브리드 지원 |
| `READ_ONLY` | 읽기·분석·보존만 가능 | 읽기 전용 |
| `PRESERVE_ONLY` | 알 수 없는 구조를 손상 없이 보존하나 생성/수정하지 않음 | 보존 전용 |
| `OPTIONAL_EXTERNAL` | 외부 API/제품/라이선스가 있을 때만 지원 | 선택 연동 필요 |
| `DISABLED_BY_POLICY` | 기술적으로 가능해도 기본 보안 정책상 비활성 | 관리자 승인 필요 |
| `UNSUPPORTED` | 대상 버전에서 안전한 구현 경로가 없음 | 지원하지 않음 |

## 핵심 지원 목표

GA에서는 다음 도메인의 핵심 기능이 `DIRECT_FULL`, `AUTOMATION_FULL`, `HYBRID` 중 하나여야 한다.

- 파일 열기/저장/새 문서/템플릿/끼워 넣기
- 글자·문단·스타일·번호
- 용지 크기·방향·여백·구역·다단·머리말/꼬리말·쪽 번호
- 표 구조·셀 속성·표 계산
- native 수식
- 그림·도형·글상자·차트·캡션
- 필드·책갈피·하이퍼링크·상호 참조·각주/미주·차례/색인
- 검색/치환과 안전한 편집 transaction
- 메모·변경 추적의 보존과 기본 조작
- PDF/이미지/텍스트 내보내기와 인쇄 설정
- 문서 암호/배포용 문서/개인정보 보호의 안전한 처리 정책

## 명시적 비목표

- 사용자 동의 없이 임의 매크로 실행
- 비밀번호 우회, 배포용 문서 보호 우회, 전자서명 위조
- 상용 폰트 무단 배포
- 한컴 계정/클라우드 서비스의 비공식 자동화
- GUI 픽셀 좌표 클릭을 일반 구현 경로로 사용하는 것
