# 사용자 사례 전수 목록

> 기준일: 2026-08-31  
> 프로젝트 코드명: `hwpx-agent`  
> 문서 세트 버전: `2.0-design`  
> 규범 키워드: **MUST/SHALL=필수**, **SHOULD=권장**, **MAY=선택**


## 핵심 제작

- 빈 HWPX 작성, 기존 양식 기반 작성, 여러 문서 끼워 넣기, 문서 분할/병합.
- A4/A3/B4/사용자 정의 크기, 세로/가로, 맞쪽, 구역별 다른 용지, 다단 편집.
- 교안·시험지·공문·보고서·논문·신청서·라벨·원고지 작성.
- 복잡한 표와 표 계산, 반복 머리행, 셀 병합/분할, 표 캡션.
- LaTeX/MathML/EqEdit를 native 한컴 수식으로 변환하고 기존 수식을 의미 단위로 수정.
- 그림·도형·글상자·글맵시·차트·OLE를 삽입·배치·서식 지정.
- 필드, 양식 개체, 메일 머지, 책갈피, 하이퍼링크, 상호 참조, 각주/미주, 차례/색인/참고문헌.

## 수정과 보존

- 특정 제목·표·문항·책갈피·필드를 찾아 내용/서식만 교체.
- 학교/기관 template의 미지 구조, 서명란, 배경, 마스터 요소를 보존.
- 문서 전역 찾기·바꾸기, 글자 모양/문단 모양 일괄 수정.
- 메모와 변경 추적을 보존하거나 승인된 범위에서 추가·적용·취소.

## 검증과 변환

- 실제 한/글 열기/저장 후 의미 보존 검증.
- PDF/이미지/텍스트/HTML/지원 Office 형식 내보내기.
- 페이지 넘침, 표/문항 분할, 잘린 수식·그림, 폰트 대체, 링크 깨짐 탐지.
- 보안 위험, 외부 링크, 스크립트, OLE, 개인정보 패턴 검사.
