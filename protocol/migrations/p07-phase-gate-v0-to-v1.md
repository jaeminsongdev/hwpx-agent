# P07 phase Gate v0 to v1

There is no stored P07 phase Gate v0. Version 1 introduces the first aggregate contract over the
nine P07 task validators and the bounded direct/automation differential validator.

The aggregate validator MUST NOT convert a component-level `pass` into phase completion. P07-07 is
closed only when exact-target execution, raster output and the user's `user_attested` original-detail
review agree. Structural raster measurements, automation success, or assistant inspection alone are
insufficient. Until then, P07 remains `in_progress` and P08 remains blocked.

The first v1 checkpoint intentionally records 8/9 tasks closed. A later promotion may change the
Gate decision only by adding a hash-bound P07-07 target qualification and rerunning every constituent
validator. It MUST NOT relabel failed predecessor attempts, activate the high-error general estimator,
or expand the exact current-PC Hangul 2020 result to arbitrary documents, other versions, production,
or whole-product completion.
