# P08 object remainder HWPX v0 to v1

There is no accepted v0 direct-HWPX contract for these nine remainder capabilities. Version 1
adds eight bounded preserving HWPML profiles and one typed unavailable reason. The current
revision additionally qualifies exact plain-static caption insertion and one hash-bound static
edit-form insertion profile.

Consumers must not infer `obj.aspect_lock` from `hp:sz@protect`, must not discard an alt-text
title, and must not synthesize missing gallery or paragraph-band native payload. Form and caption
insertion are available only inside their exact qualified profiles.
Unsupported or rejected profiles return `CAPABILITY_UNAVAILABLE_FOR_TARGET` before effect. There
is no compatibility fallback to dialog-mediated desktop automation.
