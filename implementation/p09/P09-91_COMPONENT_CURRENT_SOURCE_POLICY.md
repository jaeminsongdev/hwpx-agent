# P09-91 원래 컴포넌트 현재 소스 검증 정책

## 범위와 원래 경로

원래 필드·양식·주석·링크·교차 참조·목차/색인·인용·메일 병합·보조 참조 및
책갈피/주석/하이퍼링크 HWPX 검사 12개에 명시적 --current-source-v2 모드를 연결한다.
기본 historical_v1 결과, 구현 잠금 상수, 계약·source qualification·문서·보고서·
기존 테스트는 유지한다. 원래 검사 조건과 오류는 제거하지 않는다.
현재 구현 비교만 별도 고정 지문을 선택하고, 추가 불변 기록 검증을 수행한다.
기본 결과와 보관된 원래 검사 결과는 모든 반환 항목을 대조한다.

현재 모드는 별도 validation/v2 형식을 사용하며 historical_schema_version을 남긴다.
새 형식의 검사 증거이지 원래 제품 API 또는 기능 소유권 변경이 아니다.
호출자 지문, 불명확한 모드, 추가 CLI 플래그, 현재 모드의 계약/qualification
override는 거부한다. 기존 기본 모드의 override 검사 인터페이스는 유지한다.

## 실제 파일과 검사

qualification.v2.json 전체 바이트/크기/SHA-256을 고정하고 172개 raw 파일을 확인한다.
공식 소스 68개, 원래 계약·문서·검증 기록과 현재 구현, 실제 재실행한 Rust 실행 파일
14개, 원래 공개 API 파일과 새 마이그레이션을 포함한다. 공개 API 검사도 그대로 수행한다.
현재 구현의 raw/UTF-8 정규화 방식은 원래 검사별 방식과 일치해야 한다.

보조 참조의 원래 공식 지문은 UTF-8 BOM을 제외하고, 다른 공식 지문은 BOM을 유지한다.
해당 차이를 고정된 family별 방식으로 명시하여 각 실제 소스에 대해 확인한다.
정규화가 맞는 쪽을 임의 선택하지 않는다. 실제 공식 파일의 BOM 포함 전체 바이트는
항상 raw 잠금으로 보존한다. BOM 제거와 줄바꿈 변경도 raw 지문이 다르면 거부한다.
원래 공식 지문이나 실제 공식 파일을 수정하지 않는다.

원래 Rust 공개 컴포넌트 116개와 해당 내부 계획 변조 12개를 포함한 128개를
실제로 재검증한다. domain-ir 라이브러리의 다른 내부 검사 9개도 함께 실행되어
실제 실행 합계는 137개다. 기존 코드의 변화가 공유 lib.rs에만 있는 것으로 가정하지 않는다.
변조 검사는 테스트 소유 복사본에만 적용하며 실제 제품·native 증거로 사용하지 않는다.

## Gate 및 보존

이 검사는 동일한 원래 typed 컴포넌트와 HWPX fixture 처리의 현재 소스 증거다.
설치된 한글의 의미·저장/재열기·시각·렌더링·native 작성자/시각/표시/해결 상태,
전체 댓글 또는 전체 문서 제품 경로, 발급자·원자적 실행·공개 권한을 증명하지 않는다.
기본 검사 15개는 2 PASS / 13 FAIL이고 원래 conformance는 fail:matrix_drift를 유지한다.
현재 프로필을 원래 conformance 경로에 연결하는 별도의 검증은 아직 남아 있다.
