## Qualified native boundary

defines inline `titleMark` with exact `ignore` Boolean state; `indexmark` with `firstKey` and optional
`secondKey` string children; and the generic `fieldBegin`/`fieldEnd` envelope with field type

## Complete typed state

`hwpx-agent.toc-index/v1` binds ordered complete section, TOC-source, TOC-mark, index-mark,
generated-TOC, and generated-index inventories. TOC sources carry exact anchors, levels 1 through
10, text, numbering linkage, style, page assignment, opaque state/properties, and protection. A
TOC mark identifies one live source, stays inside its source anchor, and preserves the exact native
`ignore` state. An index mark binds logical/control identity, exact anchor, first and optional second
key digests, paired collation-key digests, page assignment, native payload, opaque properties, and
protection.

TOC generation settings bind the selected inclusive level interval, one style digest per level,
page-number and alignment policy, hyperlink choice, leader kind, page format, and numbering render
policy. Index settings bind locale, collation profile, heading/entry/subentry styles, page format,
duplicate-page policy, and column layout. Generated bodies preserve the exact generated-content
digest and a projection digest over the complete applicable marks, sources, and settings.

Sorted complete occupied non-TOC/index control, field-ID, and field-name-digest inventories prevent
global native collisions. Document state also binds run/inline topology, page assignment,
non-TOC/index content, unrelated fields, references, notes, objects, numbering, styles,
relationships, resources, protection, and opaque document state.

## Transition, cache, and preservation rules

Insertions require exact list positions, valid sections and anchors, fresh logical/native IDs, and
non-colliding field names. Hiding is an exact `false` to `true` transition on one unlocked
`titleMark`; repeated hide fails closed. A generated body is `Current` exactly when its stored source
projection matches the complete current projection and otherwise must be `Stale`. Create accepts
only `Current`; later mark or visibility changes retain generated bytes and reclassify the body
`Stale` without pretending to update it.

Document and section locks reject mutation; mark locks reject hide. Each operation changes only its
owned ordered inventory and, when dependencies change, generated-cache status. All unrelated
inventories and opaque values remain byte-for-byte equal. Request creation, plan construction, and
build independently recheck canonical source-state and document-flow SHA-256. The sealed plan covers
capability, request, source/target state, source/target flow, and operation. Strict JSON rejects
duplicate or unknown keys; all input, output, and collections are bounded without truncation. Debug
output redacts identities, anchors, keys, digests, generated content, and opaque payloads.
