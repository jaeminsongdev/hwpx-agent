## 선택과 두 마스킹 정책

원본 document/section/node 집합과 NFC index SHA·경계에 결속한 selection을 받는다. hidden/MEMO 포함 여부를
명시하고 제외된 문단은 편집 전에 제거한다. 원본 scalar를 일부만 잘라낼 수 없는 NFC 조합/재정렬은 거부한다.
PerOriginalScalarPreserveSlots는 Unicode scalar마다 원래 run/text 슬롯을 유지해 별표를 놓는다. byte·UTF16·
grapheme 개수와 다르다. ThreeAsterisksPerTextGroup은 컨트롤/문단으로 나뉜 연속 글자 묶음마다 별표3개를
첫 원본 기여 위치에 넣고 다른 run/text shell은 유지한다. 두 정책을 Native 자동 기본값으로 선택하지 않는다.

한 전체 원본 proof와 whole protection observation, field/review/index, 기존 typed planner/writer/readback을
사용한다. table lock·paraTcId/charTcId=0·필드 cache와 header 보호 신호는 이미 가려진 글자라도 먼저 거부한다.
공유 source/plan/reader의 코드는 변경하지 않았으며 글자마다 재수입하거나 XML/보호 전체를 반복하지 않는다.
