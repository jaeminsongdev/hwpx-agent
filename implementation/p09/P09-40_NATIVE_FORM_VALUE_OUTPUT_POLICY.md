## Limits and privacy

Finite hard ceilings:32 MiB archive,2 MiB per expanded part,16 MiB expanded total;
also use the original reader/graph/domain limits. Reject invalid bounds without
clamping. Measure escaped UTF-8/XML byte length before one allocation and enforce
the caller's output-part bound. Reject invalid XML characters, overlap, arithmetic
overflow, out-of-range spans, and over-limit ZIP writes/seeks before allocation.
Return no partial package. The ordinary ZIP writer may emit its own constant
drop-finalization diagnostic on a deliberately failed limit probe; do not hide
or treat that as success.

Debug output and public hash/count receipts contain no document values/private
paths. Do not print complete private states, source/output XML or full logs.
Original captures are read-only, hash/size/link checked. Ordinary tests keep
output in memory. Explicit qualification generates exactly five source/output
pairs plus one hash/count-only manifest (11 files, <=1 MiB total) in an initially
empty, dedicated `p09-40-component-*` direct child of fixtures/target-build.
Reject relative/traversal/nested/wrong-prefix/nonempty/link/reparse destinations;
use exclusive file creation, never overwrite. The qualifier owns/cleans only
its bounded temporary directory. No unbounded environment-directed file writer.
