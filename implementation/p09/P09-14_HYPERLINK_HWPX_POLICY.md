# P09-14 Hyperlink HWPX policy

Status: `exact_static_section_integration_pass / licensed_discovery_source_qualified /
generated_target_execution_not_run / non_green`.

## Exact admitted profile

`hwpx-agent.hyperlink-hwpx.hangul-2020-https-current-tab/v1` supports REF-033 hyperlink insertion
and REF-034 target editing only for an approved safe HTTPS target. It implements the exact structure
observed in licensed Hangul 2020 build `11.0.0.9136` x86 ko-KR: a begin-control run, one existing
plain-text display run, and an end-control run. The begin field has `id/type/name/editable/dirty/
zorder/fieldid`; the end field has `beginIDRef/fieldid`; both identities must agree.

The parameter list is exactly six ordered entries: integer `Prop=0`, then strings `Command`, `Path`,
`Category`, `TargetType`, and `DocOpenType`. `Command` is `https\://...;1;0;0;`, `Path` is the exact
approved URI, and the remaining values are `HWPHYPERLINK_TYPE_URL`,
`HWPHYPERLINK_TARGET_BOOKMARK`, and `HWPHYPERLINK_JUMP_CURRENTTAB`. Extra, missing, reordered,
comment-bearing, stray-text, opaque or namespace-local payloads fail closed.

## Range and transition boundary

Insertion wraps exactly one existing run containing one non-empty plain-text `t` node. Its normalized
anchor is `[inline 0, inline 1]`; hyperlink boundary runs are excluded from normalized run ordinals.
The existing display run bytes and character property reference are preserved exactly. Editing may
change only the approved HTTPS target and the bound native-parameter digest. Display-text changes,
multi-run ranges, nested markup, alternate field shapes, internal/mailto/managed targets and new
style creation are non-representable.

The v2 domain transition binds target and `new_parameters_sha256` together. Every exact-profile entry
has empty field name and opaque digests, `editable=false`, `dirty=true`, `z_order=-1`, no sub-list or
meta tag, and no opaque properties or lock.

## State, preservation and safety

The adapter binds the complete `LinkReferenceDocumentState`, source/target state SHA-256,
source/target document-flow SHA-256, complete section SHA-256, ordered existing hyperlink wrapper
digests and a sealed bounded plan. Planning and lowering independently recheck state, flow, section,
projection and plan integrity. Insertion performs one exact run replacement containing the untouched
display bytes; editing replaces only the parameter subtree. Output is read back against the complete
typed target state and every byte outside the single declared edit is proven unchanged.

Inputs, elements, paragraphs, runs, hyperlinks, text, plan JSON and output are finitely bounded.
Unknown/malformed XML, ID disagreement, unapproved URI, wrong digest, source drift and allocation
failure return no partial output. Debug output redacts URI, display text, identities and digests.
