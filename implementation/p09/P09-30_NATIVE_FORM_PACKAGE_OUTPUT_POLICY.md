# P09-30 complete native-form package output policy

Version: 1. Updated: 2026-10-02. State: component implementation, non-green.

## Scope and predecessor preservation

Implement actual complete package output for global `ref.form_properties` and
`ref.form_tab_order`, preserving P09-29 reader/binder and P09-28/r02 public
exports byte exactly. Compile the new production module through a separate
pending-export integration target. Do not fabricate native IDs, normalize
unrelated XML, replace the legacy ID index, or reinterpret rejected operations.

The immutable P09-29 source capsule remains SHA
`82a4112980c36bb901870d88d28810913bdbe64e7b3002f8b117b090bfcb9367`.
Every one of its 15 raw sources and earlier explicit source/export history
must remain valid; independently reproduce the predecessor rather than refresh
it. No public export/source lock change is implied by this component.

## Production output contract

- Source archive, complete ordered map, all observed native identities/anchors,
  actual catalogs/resources/references/protection/opaque bindings and explicit
  caller defaults/validation are revalidated using the unchanged real binder.
- Immutable output plan has private fields, redacted Debug, no Deserialize.
  Reconstruct and reseal against the actual current source before any lowering.
- Use the full global domain state once, not local contiguous tab sequences or
  per-section required radio groups. A required radio group may cross sections.
  Input/default/validation changes, insertion, opaque commands, identity,
  geometry, anchors, payload and changed document flow are not silently dropped.
  Their full product requirements remain open pending a qualified implementation.
- Change only semantically changed common or character attribute value spans.
  Optional absent groupName may be inserted. Preserve other lexical forms,
  quotation styles, attribute order and every byte outside declared edits.
  Escape literal XML characters and encode attribute whitespace as references.
- Independently reread section observations and the complete output package.
  Compare every full global state field and actual unchanged package binding,
  native optional IDs, physical paths, payload, geometry, opaque state and
  non-form content. Compare all expanded parts against the derived expected
  bytes, complete entry order and compression. An external verifier trusts no
  claimed receipt and rejects substituted/omitted/extra/reordered output parts.
- Finite output ceilings: archive 32 MiB, each part 2 MiB, total expanded 16 MiB,
  attribute input 64 KiB; smaller explicit limits honored, no silent clamping.
  Seekable ZIP output checks allocation/seek/write before crossing its bound.
  Failure returns no partial artifact. Complete ZIP integrity/closed graph and
  independently checked closed native overlay must pass on the returned output.
- ZIP headers, timestamps, extra fields and compressed byte streams are
  rewritten, not raw-preserved. Report `rewritten_not_byte_exact`; preservation
  claims concern expanded content, complete order and compression methods.
- Original legacy `id_index_validation_failed` and exact independently checked
  native overlay issue count stay visible. Never claim legacy index PASS.
- Unqualified nonzero border types and observed protection/signature signals
  stay fail-closed. Marker absence is not a general unlocked guarantee. Never
  execute document commands or change registry/trust/permission settings.

## Independent qualification

The unchanged exact P08-20 native source is preserved (14,556 bytes, SHA
`02e9b5acef95877b6934a6a3131069402138cc2190eff2e68db79aa7e9ac9ce7`).
New actual production code is compiled and executed with locked/offline Cargo,
not replaced by a test implementation. Optional exclusive temporary artifacts
are emitted only to a supplied absolute existing non-linked oracle directory;
fixed names, create_new, bounded bytes, no original overwrite or path printing.

The Python oracle independently reads actual Rust-generated source/output
archives without extraction, bounds all inventories/expanded bytes/CRC, and
compares every part/order/compression. Its actual property case requires exactly
the original archive and one enabled-value edit. Three complete multi-section
tab/radio fixtures are independently derived from that exact capture; no claim
that these derived fixtures were opened by Hancom. Oracle checks complete source
derivation first, then only the declared global tab edits and all untouched bytes.
Public metadata contains only relative source pins, hashes, counts and statuses.
The actual property probe must exactly match independent output evidence with
strict types. Rust alone proves the canonical full typed target-state digest;
the Python oracle does not claim an independent full domain serializer.

Failed/skipped/missing/extra test names, forged source/output/probe, source drift,
missing original and changed predecessor authority must fail, not be skipped.
Publish append-only canonical public capsule and reproduce its exact bytes.

## Product and native boundary

No new Hancom/COM/UI, permission action, native save/reopen, render, comparator,
public package exports or production route qualification follows from these
component tests. Full actual disposable cases and the saved/reopened oracle
remain next work after explicit export/source succession. P09 Green remains
zero; P09/product Gate NOT_RUN. Other native form types, input/default/validation,
border/protection, note body-numbering/raw binding, CLICK_HERE styling, caption
visuals, fields/comments/links, mixed documents and differential/route acceptance
remain required by the full P09-P20 goal. No P10 new implementation before P09 Gate.

Gather all dependency-ready permission-required cases into one preflighted batch
before dispatch; never run isolated 1-2 ready cases or unchanged/invalid cases to
inflate prompts. The user alone handles sequential permission dialogs. Preserve
P08/P09/P17 originals, dirty changes, private evidence and failed receipts. No
stage/commit/push, deletion/move, security settings or external effects implied.
