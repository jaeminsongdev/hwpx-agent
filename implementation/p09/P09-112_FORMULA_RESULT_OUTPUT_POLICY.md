# P09-112 — 원래 계산값의 실제 문서 결과 반영 정책

## 범위와 실행 경계

원래 source-backed numeric evaluator의 ALL admitted formula results를 기존 preserving package 경로에 연결한다.
caller 값/AST/XML/offset/metadata/approval/artifact selector를 받지 않는다. 원래 importer·수식 envelope·
General format·AST·Command/LastResult/visible parity·canonical decimal·source owner/grid·budget 검사는 그대로다.
입력 원본이나 cache를 in-place 수정하지 않으며 별도 immutable memory artifact만 생성한다.

수학적 계산 및 output re-import는 native recalculation/field permission/full importer/author/time 의미 증거가 아니다.
native caches는 출력에서도 Unverified다. full field policy/issuer/atomic execution/publication/SQL/P09 Gate는 미완료다.
Stored candidate의 require_current_product_route는 fresh 원본 검사 후 RouteUnqualified를 유지한다.

## 결과 변경과 보존

원래 source begin anchor만 선택한다. 계산값과 현재 unverified decimal cache가 같으면 변경하지 않는다.
다른 경우 source-bound Command/LastResult/visible result 세 leaf를 함께 바꾸며 수식 AST와 format은 바꾸지 않는다.
모든 결과가 같으면 NoChange, formula가 없으면 NoTargets다. 보호 검사와 원본 검사는 no-op/writer 전에 수행한다.
원래 P111 actual ancestor/consumed protection guard를 crate 내부에서 재사용하며 규칙/boolean parser를 완화하지 않는다.
보호 flag 부재는 승인 의미가 아니며 full document policy/permission을 대체하지 않는다.

기존 patch engine에 semantic PatchText만 받는 ReplaceLeafText를 추가한다. root, child element, comment는 거부한다.
기존 source selector/byte fingerprint/token-stable preservation/budget/conflict/ID/graph/writer 검사를 재사용한다.
닫힌 leaf는 원래 start/end tag·attribute·namespace 그대로다. self-closing leaf의 '/>'만 같은 원래 name의 닫는 tag로
확장한다. raw XML은 입력으로 받거나 실행하지 않는다. 이 확장은 선언된 leaf edit 범위이며 바깥 bytes는 불변이다.

한 batch의 source/result command·cache·visible field parity와 전체 package part bytes를 독립 재검증한다.
source numeric input/AST/owner/grid/format·field/meaning inventory·계산값을 다시 import하고 비교한다.
어떤 source/profile/protection/budget/readback 실패에서도 부분 artifact를 반환하지 않는다.

## 저장된 원본과 권한

Stored provider의 원래 revision-selected source, ACL/AEAD/scanner admission/actor/tenant/project/branch/document/
head checks와 whole source/math/output receipt replay를 전후에 유지한다. cached receipt/getter는 실행 권한이 아니다.
권한 회수·암호문 변조·quarantine·head/scope 변경 후 callback은 실행되지 않는다.
반복 read는 held lease가 아니며 ingest/commit/publication을 하지 않는다.
