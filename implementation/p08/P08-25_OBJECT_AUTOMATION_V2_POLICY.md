# P08-25 object automation v2 policy

## Scope

Qualify the 42 P08 automation fallback routes only for licensed Hancom Hangul 2020
`11.0.0.9136` x86 on the current PC. The candidate overlay is immutable input. Runtime promotion
requires an exact feature/capability identity, exact executable hash, observed semantic effect,
bounded rollback, zero document saves, and zero remaining owned HWP processes.

Named project-owned P08-20 readback fixtures may be opened solely to establish a selected-object
context. User documents, external network, registry/system settings and Computer Use input are out
of scope. Modal or no-effect attempts are retained as negative evidence and cannot be routed.

## Differential rule

The direct and automation routes are compared against the same pinned capability contract and the
same exact target. `exact_match` means both produced the required semantic effect under that
contract; it does not mean the two serializers emitted identical bytes. An unavailable fallback is
`not_applicable_fallback_unavailable` only when the preferred direct route is independently
`oracle_verified`. A missing target capability is never green.

## Completion rule

- 34 verified exact-target automation routes are enabled only in the qualified v2 overlay.
- 8 unavailable routes remain disabled with exact reasons.
- 41 independently verified preferred direct routes may be P08 green.
- `OBJ-044` remains `CAPABILITY_UNAVAILABLE_FOR_TARGET`, non-green and non-advertised.
- P11, other builds/PCs, arbitrary documents, production and the whole product remain unclaimed.
