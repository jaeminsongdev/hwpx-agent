## Locked architecture and failure boundaries

- MCP Apps is the portable UI foundation. `window.openai` is used only after capability detection
  for a ChatGPT extension with no shared MCP Apps equivalent.
- P15 data/action tools remain useful without UI. Only dedicated, versioned render tools may name a
  `ui://` resource served as `text/html;profile=mcp-app`.
- `.codex-plugin/plugin.json` is the package entry point. `.app.json` is only for an actual
  registered remote mapping; no `plugin_asdk_app...` identifier is invented. `.mcp.json` remains a
  distinct bundled-server mechanism.
- Model-visible results are limited to schema-valid opaque IDs and bounded summaries. Raw document
  bytes/XML, HAction/COM names, arbitrary paths, credentials and unbounded content are forbidden.
- CSP defaults to wildcard-free exact HTTPS origins with nested frames disabled. Every write or
  destructive operation needs explicit user confirmation and server-side authorization.
- Actual Developer mode, file-library and current-PC Hangul web execution evidence stays
  `unverified` until its own user-operated acceptance session.
